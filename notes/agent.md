# Agent 与工具调用

## 工具的两个部分

工具描述告诉模型工具名、用途和参数结构；工具实现是真正在程序中执行的函数。给模型发送描述不会自动执行本地代码。

JSON Schema 用于描述工具参数，例如要求 timezone 是必填字符串。程序仍应验证模型实际生成的参数。

## 工具调用循环

一个基本 Agent 循环包括：请求模型、检查工具调用、执行工具、回传结果、再次请求模型。没有工具调用并得到回答时结束。

模型负责提出工具调用请求，程序负责执行本地函数。工具执行完后再次请求模型，是为了让模型依据工具结果组织回答或决定下一步。

## Responses 风格的工具消息

function_call 表示模型提出的函数调用，包含 name、arguments 和 call_id。arguments 是 JSON 字符串，需要解析后再使用。

function_call_output 表示程序返回的工具结果。call_id 将结果与具体调用对应起来。回传结果时，也要保留对应的工具调用记录。

## 当前项目的实现

当前教学项目的时间工具名为 get_current_time，接收 timezone 参数。它读取本机时钟，并根据时区格式化时间。

模型正文逐段显示，工具参数则在完整响应到达后读取。这样可以避免对尚未拼接完整的参数执行 JSON.parse()。

每轮用户提问最多请求模型 5 次。达到上限仍要求调用工具时停止，避免无限循环。工具参数错误作为结果回传，模型可以尝试修正。

## 当前历史的范围

本轮内部输入保存工具调用和工具结果。跨轮聊天历史目前只保存用户问题和助手正文，不保存完整工具轨迹。
