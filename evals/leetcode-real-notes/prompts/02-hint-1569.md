力扣 1569：统计数组重排后仍生成同一棵 BST 的方案数，排除原序列。我认为根不能变，同一个子树内的先后顺序也不能变，所以写了下面的公式。

```python
class Solution:
    def numOfWays(self, nums: list[int]) -> int:
        # 思考：怎样重新排序才能得到相同的bst？
        # 首先，根节点是不能变的，其次，我猜，就是同属一个子树的元素的先后次序不能变
        # 那么，假设数组长度是n，然后排除根节点就是n - 1个位置，设左子树x，右子树y，x + y == n - 1
        # 可得到的排序方案数是C_(n - 1)^(x)，排除原数组，还要减一
        n = len(nums)
        left_tree_size = sum([1 for num in nums[1:] if num < nums[0]])
        return math.comb(n - 1, left_tree_size) - 1
```
