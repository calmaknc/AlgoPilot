## 思路

链表按低位到高位存储数字，可以从头开始做竖式加法。每位用两个节点的值加上上一位的进位；总和对 10 取余得到当前位，整除 10 得到下一位的进位。结果用哨兵节点和尾指针逐个追加。

一条链表先走完时，相当于它的高位补 0，继续处理另一条链表和进位。两条链表都走完后，如果仍有进位，要追加一个最高位。例如 `9 → 9` 加 `1` 得到 `0 → 0 → 1`，即 99 + 1 = 100。

## 我的代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        carry = 0
        dummy = tail = ListNode()
        while l1 and l2:
            newVal, carry = (l1.val + l2.val + carry) % 10, (l1.val + l2.val + carry) // 10
            newNode = ListNode(val = newVal)
            tail.next = newNode
            tail = tail.next
            l1 = l1.next
            l2 = l2.next

        while l1:
            newVal, carry = (l1.val + carry) % 10, (l1.val + carry) // 10
            newNode = ListNode(val = newVal)
            tail.next = newNode
            tail = tail.next
            l1 = l1.next

        while l2:
            newVal, carry = (l2.val + carry) % 10, (l2.val + carry) // 10
            newNode = ListNode(val = newVal)
            tail.next = newNode
            tail = tail.next
            l2 = l2.next

        if carry != 0:
            tail.next = ListNode(val = carry)

        return dummy.next
```

- 时间 O(max(m, n))，m、n 为两个链表的长度；不计结果链表，额外空间 O(1)。
- 逻辑可统一为 `while l1 or l2 or carry`：缺位按 0 处理，`carry, digit = divmod(total, 10)` 一次取出进位和当前位。原版分段写法同样正确。
