## 我的原始代码

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        # 这题我见过，翻转图像就是先转置，后左右翻转
        m, n = len(matrix), len(matrix[0])
        for i in range(m):
            for j in range(n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        for i in range(m):
            for j in range(n // 2):
                matrix[i][j], matrix[i][n - j - 1] = matrix[i][n - j - 1], matrix[i][j]
```

## Bug：转置时每对对称元素交换了两次

遍历整个矩阵时，非对角线的每对 `(i, j)`、`(j, i)` 都会遇到两次：

```text
i = 0，j = 1：交换 matrix[0][1] 和 matrix[1][0]。
i = 1，j = 0：把这两个元素又交换回来。
```

因此整个转置阶段结束后矩阵仍与原来一样，最终只完成左右翻转，没有完成旋转。对角线元素与自身交换，虽无影响，但也不必处理。

最小修正：只遍历主对角线的一侧，例如 `j in range(i + 1, n)`，让每对元素只交换一次。也可选择下三角，但不能两边都遍历。

### 本地复现的反例

```text
输入：             原版最终结果：    正确旋转结果：
1 2               2 1              3 1
3 4               4 3              4 2
```

原版转置循环后仍为 `[[1, 2], [3, 4]]`；左右翻转后得到 `[[2, 1], [4, 3]]`。

## 修正版参考代码

以下为助手此前给出的修正版。本人反馈修改后提交通过，未另提供最终提交源码，不将其作为本人提交源码的逐字记录。

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        n = len(matrix)

        # 转置：只遍历主对角线上方
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 每行左右翻转
        for i in range(n):
            for j in range(n // 2):
                matrix[i][j], matrix[i][n - j - 1] = (
                    matrix[i][n - j - 1], matrix[i][j]
                )
```

题目是 n×n 方阵，使用一个 n 即可。左右翻转也只遍历半行，避免左右两端再次交换回来。

## 数学解释：顺时针旋转为何等价于转置加左右翻转

矩阵下标从 0 开始，行号向下增加，列号向右增加。跟踪原位置 `(i, j)` 的元素去向。

### 顺时针旋转 90° 的目标坐标

```text
(i, j) → (j, n - 1 - i)
```

新行号是原列号 j；原来从上向下排列的各行，旋转后从右向左排列，所以新列号为 n-1-i。

也可以以矩阵中心 `c = (n-1)/2` 建立常规数学坐标：向右为 x 正方向，向上为 y 正方向。原元素坐标为 `x = j-c`、`y = c-i`。顺时针旋转后 `(x', y') = (y, -x)`，转回矩阵下标：

```text
新行号 i' = c - y' = c + x = j
新列号 j' = x' + c = y + c = n - 1 - i
```

因此目标坐标确实为 `(j, n-1-i)`。

### 两次操作的复合坐标

1. 转置交换行列：`(i, j) → (j, i)`。
2. 左右翻转保持行号不变，将列号 q 映射为 n-1-q：`(j, i) → (j, n-1-i)`。

复合结果与顺时针旋转的坐标完全一致，因此两种做法等价。

```text
原矩阵：      转置：        左右翻转：
1 2 3         1 4 7        7 4 1
4 5 6    →    2 5 8   →   8 5 2
7 8 9         3 6 9        9 6 3
```

顺序不能随意交换：先左右翻转、再转置，会得到 `(i, j) → (i, n-1-j) → (n-1-j, i)`，对应逆时针旋转 90°。

几何上，转置是沿主对角线反射，左右翻转是沿竖直中线反射；两条轴夹角 45°，连续两次反射合成为 90° 旋转，方向取决于操作顺序。
