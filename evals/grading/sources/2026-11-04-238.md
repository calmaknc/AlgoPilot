## 思路

每个位置的答案等于：**左侧所有元素的乘积 × 右侧所有元素的乘积**，两部分都不包含当前位置。

- 从左往右，先将此前的 prefix 写入 res[i]，再乘上 nums[i]，供下一个位置使用。
- 从右往左，先将此前的 suffix 乘入 res[i]，再乘上 nums[i]，供下一个位置使用。
- 必须先使用再更新，否则会把 nums[i] 自身也乘入答案。
- prefix、suffix 初始化为 1，表示没有元素时的空积，适用于首尾位置；res 也初始化为 1，方便累乘。

例如 nums = [1, 2, 3, 4]：

```text
左侧积： [1, 1, 2, 6]
右侧积： [24, 12, 4, 1]
对应相乘：[24, 12, 8, 6]
```

## 我的代码

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        res = [1] * n

        prefix = 1
        for i in range(n):
            res[i] *= prefix
            prefix *= nums[i]

        suffix = 1
        for i in range(n - 1, -1, -1):
            res[i] *= suffix
            suffix *= nums[i]

        return res
```

独立运行需导入 `from typing import List`，或改用 `list[int]` 注解。

## 复杂度与验证边界

- 时间 O(n)，两次遍历。
- 不计输出数组，额外空间 O(1)：只需 prefix、suffix 等变量；计入输出则为 O(n)。不需要额外建立两个长度为 n 的前后缀数组。
- 不使用除法，自然支持零和负数。例如有一个零时，只有该位置的答案可能非零；有至少两个零时，所有答案均为零。
