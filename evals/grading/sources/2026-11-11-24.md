## 我的递归代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        if head is None or head.next is None:
            return head

        node1 = head
        node2 = head.next
        node3 = node2.next

        node1.next = self.swapPairs(node3)
        node2.next = node1

        return node2
```

递归约定：返回这一段链表两两交换后的新头。当前一对为 A、B 时，先让递归处理剩余链表，A 接到递归返回的新头，B 再接到 A 前面，最后返回 B。剩下零个或一个节点时直接返回，所以奇数长度的最后一个节点保持不动。

## 迭代：每轮改三条链接

你的四个位置都找对了：上一组的尾节点 prev、当前一对 A 和 B，以及剩余部分的头 rest。这里的 rest 可以是 None。用 dummy 作为第一组的前驱，让头部换位也能走同一套逻辑。

```text
交换前：prev → A → B → rest
交换后：prev → B → A → rest
```

先保存 A、B 和 rest，再按这个顺序改写：

1. `prev.next = B`：前驱接到交换后的组头。
2. `A.next = rest`：A 接上后续链表，断开 A 到 B 的旧链接。
3. `B.next = A`：完成组内换位。先断开 A 到 B，可以避免中途形成两节点环。

**不必让两个指针各走两次。** A 已经是本组的新尾节点，直接设 `prev = A`。下一轮的 A 就是 `prev.next`，也就是本轮保存的 rest，无需单独维护当前指针。若分别保留前驱和当前指针，可直接更新为 `prev = A`、`curr = rest`。

例如 `dummy → 1 → 2 → 3 → 4`，第一轮变成 `dummy → 2 → 1 → 3 → 4`；prev 直接指向 1，下一轮取 prev.next 和 prev.next.next，即 3 和 4。

### 迭代参考代码

以下是助手整理的参考实现，非本人提交代码：

```python
class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        dummy = ListNode(next=head)
        prev = dummy

        while prev.next and prev.next.next:
            a = prev.next
            b = a.next
            rest = b.next

            prev.next = b
            a.next = rest
            b.next = a

            prev = a

        return dummy.next
```

两版均为 O(n) 时间。递归每两节点增加一层调用，栈空间 O(n)；迭代仅用固定数量的指针和一个哨兵，额外空间 O(1)。本次核对逻辑，未运行本地测试；平台提交结果未反馈。
