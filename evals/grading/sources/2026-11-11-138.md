## 我的思路

直接做法是用哈希表建立“原节点 → 复制节点”的映射，然后按映射接上复制节点的 next 与 random。映射要以节点身份为键，值相同的节点不能合并；额外空间 O(n)。

交错法把这个映射临时存进原节点的 next。对于原节点 A、B，有：

```text
原链表：A → B
交错后：A → A' → B → B'
```

此时 A 的副本就是 `A.next`。如果 `A.random` 指向 B，则 `A.next.random = A.random.next` 恰好把 A' 指向 B'。必须先插好全部副本，再统一复制 random，因为 random 可能指向原链表中任意位置。

## 我的原始代码

注释的缩进已统一，代码逻辑保留。

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
        self.val = int(x)
        self.next = next
        self.random = random
"""

class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        # 复制链表
        cur = head
        while cur:
            cur.next = Node(cur.val, cur.next)
            cur = cur.next.next

        # 把random也连上
        cur = head
        while cur:
            if cur.random:
                cur.next.random = cur.random.next
            cur = cur.next.next

        # 准备返回的链表
        cur = dummy = Node(0, head)
        while cur.next:
            cur.next = cur.next.next
            cur = cur.next

        return dummy.next
```

## 拆分时要同时恢复原链表

这版能返回正确连好的副本，但第三段只重接了复制节点的 next，没有恢复原节点的 next。两节点例子中，返回的是 `A' → B'`，但 `A.next` 仍指向 A'，已经不是原来的 B。

前两段可以保留，第三段换成下面的写法。每轮先保存下一个原节点，再分别恢复原节点的 next、连接副本的 next：

```python
        copy_head = head.next if head else None
        cur = head
        while cur:
            clone = cur.next
            nxt = clone.next
            cur.next = nxt
            clone.next = nxt.next if nxt else None
            cur = nxt
        return copy_head
```

此时 nxt 尚未拆分，所以 `nxt.next` 仍然是它的副本。原节点的 random 从未修改，拆分时只需处理 next。

- 时间 O(n)，不计输出的 n 个新节点，额外空间 O(1)。
- 本地复现两节点例子：原拆分的复制链表值正确，但原头的 next 仍指向复制头。恢复版在 5 组本地用例中验证了原链表恢复、副本身份独立以及 random 指向正确，覆盖空链表、自指和交叉指向。
