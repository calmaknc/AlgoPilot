## 思路

遍历数组作为快指针，slow 指向下一个非零元素的写入位置。遇到非零元素就依次写到前面，最后将 `[slow, len(nums))` 补零，保持非零元素的相对顺序。

写入位置始终不会超过当前遍历位置，因此原地覆盖不会破坏后续尚未读取的元素。

## 我的代码

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        slow = 0
        for num in nums:
            if num != 0:
                nums[slow] = num
                slow += 1

        for i in range(slow, len(nums)):
            nums[i] = 0
```

- 时间复杂度：O(n)；额外空间：O(1)。
