## 我的代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeTwoLists(self, list1: ListNode | None, list2: ListNode | None) -> ListNode | None:
        head = dummy = ListNode()
        while list1 and list2:
            if list1.val <= list2.val:
                head.next = list1
                list1 = list1.next
            else:
                head.next = list2
                list2 = list2.next
            head = head.next

        while list1:
            head.next = list1
            list1 = list1.next
            head = head.next

        while list2:
            head.next = list2
            list2 = list2.next
            head = head.next

        return dummy.next
```

## 思路与简化

两个输入链表都已按非递减顺序排列，各自的头节点是本链表剩余部分的最小值。每次取两个头节点中较小的一个，接到已合并部分之后，再推进相应指针。

dummy 是固定的哨兵节点，省去第一次接节点的特殊处理；原代码中的 head 是移动的尾指针，可命名为 tail 以免与结果头混淆。最终返回 `dummy.next`。

当第一段 while 结束，至少有一条链表已耗尽。另一条链表剩余部分已排序，且不会小于已经接上的最后一个值，可以直接接上整段。原代码最后两个 while 可替换成：

```python
head.next = list1 if list1 is not None else list2
return dummy.next
```

若两个输入都为空，直接接上 None，返回值也是 None。

- 最坏时间 O(m+n)，额外空间 O(1)，复用原节点并改写其 next。
