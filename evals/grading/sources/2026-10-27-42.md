## 先理解：每一列能接多少水

与 11 题选两条边围容器不同，本题每根柱子本身占据空间，要累加所有柱子上方的水量。

对下标 i，设 L 为 `[0, i]` 内的最高柱高，R 为 `[i, n - 1]` 内的最高柱高：

```text
水面高度 = min(L, R)
这一列的水量 = min(L, R) - height[i]
```

左右最高值均包含当前位置，因此水量不会为负。任意一侧的最高边界偏低，超过它的水都会流出去；只看相邻柱子则可能漏掉更远的挡水边界。

统一例子：

```text
height = [3, 1, 0, 2, 4]

4 |         █
3 | █ ~ ~ ~ █
2 | █ ~ ~ █ █
1 | █ █ ~ █ █
  +-----------
    0 1 2 3 4

█ 为柱子，~ 为水，总水量为 6。
```

## 方法一：前后缀分解，逐列计算

先预处理每个位置的左侧最高值与右侧最高值，再套公式累加。

```text
height  = [3, 1, 0, 2, 4]
pre_max = [3, 3, 3, 3, 4]
suf_max = [4, 4, 4, 4, 4]
water   = [0, 2, 3, 1, 0]
```

递推关系：`pre_max[i] = max(pre_max[i - 1], height[i])`；后缀同理，从右往左计算。复用相邻位置的结果，避免每列都重新向两边扫描。

以下是助手讲解参考代码，不是本人提供的提交源码：

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        if not height:
            return 0

        n = len(height)
        pre_max = [0] * n
        pre_max[0] = height[0]
        for i in range(1, n):
            pre_max[i] = max(pre_max[i - 1], height[i])

        suf_max = [0] * n
        suf_max[-1] = height[-1]
        for i in range(n - 2, -1, -1):
            suf_max[i] = max(suf_max[i + 1], height[i])

        ans = 0
        for i in range(n):
            ans += min(pre_max[i], suf_max[i]) - height[i]
        return ans
```

时间 O(n)，额外空间 O(n)。

## 方法二：相向双指针，先结算能够确定的一列

维护尚未结算区间 `[left, right]`，以及两个最大值：

- pre_max：`[0, left]` 的最大柱高。
- suf_max：`[right, n - 1]` 的最大柱高。

这两个最大值对应不同位置；中间尚未遍历。但如果 `pre_max <= suf_max`，就已经可以结算 left：

1. left 左侧的最高边界已准确知道，就是 pre_max。
2. left 右侧已经存在高度为 suf_max 的边界，它至少与 pre_max 一样高。
3. 中间即使还有更高柱子，也改变不了左侧最高只有 pre_max 的限制。

所以 left 处水量确定为 `pre_max - height[left]`，可以累加后右移 left。反之结算 right。相等时任意一侧均可。

关键不是猜测哪边移动后可能更好，而是：**当前这一列的答案已经确定，剩余未知部分不会推翻它。**

以下是助手讲解参考代码，使用 `<=` 让每个位置都明确结算一次：

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        ans = 0
        pre_max = suf_max = 0
        left, right = 0, len(height) - 1

        while left <= right:
            pre_max = max(pre_max, height[left])
            suf_max = max(suf_max, height[right])
            if pre_max <= suf_max:
                ans += pre_max - height[left]
                left += 1
            else:
                ans += suf_max - height[right]
                right -= 1

        return ans
```

原题解使用 `left < right` 也正确：按其移动规则，相遇处是全局最高柱之一，水量为 0。

在例子 `[3, 1, 0, 2, 4]` 中，右侧最高值为 4，可以从左侧依次结算出 0、2、3、1，最后最高柱接水量为 0。

时间 O(n)，额外空间 O(1)。

## 方法三：单调栈，按水平水层填坑

前两种方法逐列计算；单调栈一次计算一个水平水层，可以横跨多列。这里的“一行一行算”不是逐个整数高度枚举行，而是按柱高差一次计算整层。

栈中保存下标，对应柱高从栈底到栈顶严格递减。遇到更高或等高的当前柱时，弹出栈顶，尝试填坑：

```text
弹出的下标 bottom：本次水层的底部高度
弹出后新的栈顶 left：左边界
当前下标 i：右边界

层高 dh = min(height[left], height[i]) - height[bottom]
宽度 w = i - left - 1
新增水量 = dh * w
```

例子 `[3, 1, 0, 2, 4]`：前三个下标先入栈，栈内对应高度 `[3, 1, 0]`。

| 当前右边界 | 弹出底部 | 左边界 | 新增层高 | 宽度 | 新增水量 |
| --- | --- | --- | --- | --- | --- |
| 下标 3，高 2 | 下标 2，高 0 | 下标 1，高 1 | min(1, 2) - 0 = 1 | 1 | 1 |
| 下标 3，高 2 | 下标 1，高 1 | 下标 0，高 3 | min(3, 2) - 1 = 1 | 2 | 2 |
| 下标 4，高 4 | 下标 3，高 2 | 下标 0，高 3 | min(3, 4) - 2 = 1 | 3 | 3 |

分别计算高度 0～1、1～2、2～3 的水层，总计 6。每次只增加底部高度以上的新水层，不会把已经计算过的下层重复相加。

- 存下标而非只存高度，因为需要计算宽度。
- 使用 while，一根右边界可能连续填平多个凹槽。
- 弹出后栈空，说明没有左边界，不能围住水。
- 条件中的 `<=` 会弹出等高柱；等高时本次层高为 0，同时避免栈中保留相同高度。
- 每个下标最多入栈、出栈各一次，所有 while 的总工作量为 O(n)。

## 我的原始单调栈代码：变量覆盖

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        # 刚刚试了一列一列算，现在试一行一行算
        ans = 0
        stack = []
        for i, h in enumerate(height):
            while stack and height[stack[-1]] <= h:
                bottom = stack.pop()

                if not stack:
                    break

                left = stack[-1]
                h = min(height[left], h) - height[bottom]
                w = i - left - 1
                ans += h * w

            stack.append(i)

        return ans
```

错误在于：`h` 原本是当前右边界的柱高，却又被赋值成新增水层的高度。同一个 i 可以触发多次弹栈，下一轮 while 判断与计算仍需要原来的柱高，不能修改它。

### 本地复现反例

`height = [2, 1, 0, 2]`，正确水量为 3，原程序返回 1。

遇到最后一根柱子，原本 `h = 2`：

1. 弹出高度 0，左边界高 1，算出层高 1、宽度 1，新增水量 1；错误代码同时把 h 改成 1。
2. 继续弹出高度 1，左边界高 2；本应计算 `min(2, 2) - 1 = 1`，却算成 `min(2, 1) - 1 = 0`，漏掉宽度为 2 的上层水。

区别必须明确：**h 是当前右边界的柱高，dh 是本次新增水层的高度。**

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        # 按水平水层计算
        ans = 0
        stack = []
        for i, h in enumerate(height):
            while stack and height[stack[-1]] <= h:
                bottom = stack.pop()

                if not stack:
                    break

                left = stack[-1]
                dh = min(height[left], h) - height[bottom]
                w = i - left - 1
                ans += dh * w

            stack.append(i)

        return ans
```

时间 O(n)，额外空间最坏 O(n)。

## 三种方法的联系与验证边界

| 方法 | 何时确定水量 | 时间 | 额外空间 |
| --- | --- | --- | --- |
| 前后缀分解 | 已知该列左右最高值，按列累加 | O(n) | O(n) |
| 相向双指针 | 另一侧已知足够高，较低最高值一侧的当前列可以结算 | O(n) | O(1) |
| 单调栈 | 找到右边界，且仍有左边界，计算一层新增水 | O(n) | 最坏 O(n) |
