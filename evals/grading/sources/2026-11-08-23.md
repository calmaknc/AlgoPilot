## 我的原始代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        heap = [(i, l) for i, l in enumerate(lists)]
        dummy = head = ListNode()
        while heap:
            idx, head.next = heappop(heap, key = lambda x: x[1].val)
            if list[idx].next:
                list[idx] = list[idx].next
                heappush(heap, (idx, lists[idx]))
            head = head.next

        return dummy.next
```

## heapq 的几个用法问题

1. **`heappop` 不接受 `key`。** 它的接口是 `heappop(heap)`，只取出已经建好的最小堆的堆顶，再维护堆结构。堆的比较规则必须在建堆、入堆和出堆时一致，不能等到弹出时才临时指定优先级。Python 的 `heapq` 直接比较堆里的元素，因此应在入堆前把优先级放进元素中。原版在这里首先触发 TypeError。
2. **`(idx, node)` 的第一比较项是链表编号。** 即使去掉 `key`，它也会优先弹出编号小的链表节点。比如两条链表分别是 `[2]`、`[1]`，按编号会先取 2，而不是 1。应把 `node.val` 放在首位。
3. **列表推导不负责按值建堆。** 收集初始元组后，需要调用 `heapify(heap)` 原地建堆；另一种写法是从空列表开始，每个候选用 `heappush` 加入。建堆和后续入堆使用相同的元组结构。
4. **空链表没有候选节点。** 初始时跳过 None，弹出的节点也只有在后继非空时才补入下一节点。
5. **`list[idx]` 中的 `list` 是 Python 内置类型。** 参数名是 `lists`。这里更直接的做法是取弹出节点的 `node.next`，无需更新 `lists[idx]`。

参考：[Python heapq 文档](https://docs.python.org/3/library/heapq.html#heapq.heappop)、[同优先级时如何比较](https://docs.python.org/3/library/heapq.html#priority-queue-implementation-notes)。

## 为什么用 (node.val, idx, node)

Python 元组从左到右比较：先比值，再比链表编号，只有前两项都相等才会比较节点。若只用 `(node.val, node)`，当两个节点的值相同时，就会比较两个未定义大小顺序的 ListNode，触发 TypeError。

这里可以直接用链表编号作为第二项，因为**堆中每条链表至多有一个候选节点**：先弹出该链表当前的节点，再加入它的后继。同一条链表即使有连续的重复值，这些节点也不会同时在堆里。因此，两个同时在堆里的候选如果值相同，编号必然不同，比较会在第二项结束。

```text
(1, 0, 第 0 条链表的节点)
(1, 2, 第 2 条链表的节点)
值相等，比较 0 和 2 即可，不比较节点。
```

如果换成一个允许同一条链表的多个节点同时入堆的写法，链表编号就不一定够用，需要改用每个堆条目唯一的编号。

## 修正版：每条链表只放一个候选

与 [21 · 合并两个有序链表](2026-11-08-21.md) 相同，每条链表当前的头就是该链表剩余部分的最小节点。21 题只需比较两个头；23 题用最小堆在最多 k 个头中取出最小值，它也就是所有未合并节点里的最小值。接上它后，补入同一条链表的下一个节点。

以下是助手整理的参考修正版，未收到本人采用或提交的反馈：

```python
from heapq import heapify, heappop, heappush

class Solution:
    def mergeKLists(
        self, lists: list[ListNode | None]
    ) -> ListNode | None:
        heap = [
            (node.val, idx, node)
            for idx, node in enumerate(lists)
            if node is not None
        ]
        heapify(heap)

        dummy = tail = ListNode()

        while heap:
            _, idx, node = heappop(heap)
            tail.next = node
            tail = node

            nxt = node.next
            if nxt is not None:
                heappush(heap, (nxt.val, idx, nxt))

        return dummy.next
```

## 复杂度与验证

- 设总节点数为 N、输入链表数为 k。扫描输入和建堆共 O(k)；每个节点入堆、出堆各一次，堆中至多有 k 个节点，总时间 O(k + N log(k+1))，额外空间 O(k)。
- 复用原节点并改写其 next，不另建输出节点（哨兵节点除外）。
- 上一轮本地复现了原版 `heappop` 传 `key` 的 TypeError，单独复现了 `list[0].next` 的 AttributeError，以及对两个同值的二元组 `(val, node)` 建堆时的 TypeError。
- 上一轮参考修正版通过 6 组本地用例，包括空输入、空链表、不同链表首值逆序和重复值。本次整理未重跑；平台提交结果未反馈。
