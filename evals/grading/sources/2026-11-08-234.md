## 我的思路

先用快慢指针找中点，再用 [206 · 反转链表](2026-11-08-206.md) 的思路反转从中点开始的链表。最后从原头和反转后的新头同时向后走，将原链表两端的值依次比较。

- 偶数长度 2k：slow 停在两个中点中的第二个（下标 k），反转后半段共 k 个节点，恰好比较 k 对。
- 奇数长度 2k+1：slow 停在唯一中点（下标 k），反转的部分含中点，共 k+1 个节点。前 k 次比较两侧对称位置，最后一次中点与自身比较，无须特意跳过。

例如 `1 → 2 → 3 → 2 → 1`，从中点开始反转后，head2 依次指向 1、2、3；从原头开始比较的也是 1、2、3。**反转后的后半段耗尽，就说明所有对称位置已比较完毕。**

这里从 `pre = None` 开始反转，第一轮就将原来的中点断成新尾；每轮都先保存 `curr.next`，再改写指针，避免丢失后继。

## 我的代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        def middleNode(head):
            slow = fast = head
            while fast and fast.next:
                slow = slow.next
                fast = fast.next.next

            return slow
        
        def reverseList(head):
            pre, curr = None, head
            while curr:
                nxt = curr.next
                curr.next = pre
                pre, curr = curr, nxt
            return pre

        mid = middleNode(head)
        head2 = reverseList(mid)
        while head2:
            if head.val != head2.val:
                return False
            head = head.next
            head2 = head2.next
        return True
```

## 复杂度与验证边界

- 时间 O(n)，额外空间 O(1)。
- 原地反转会改变输入链表的结构。如果调用方要求保留原链表，可先保存反转后的头节点，比较结束后再反转一次恢复；即使发现不匹配，也要先恢复再返回。
