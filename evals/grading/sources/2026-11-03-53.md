## 我的代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        dp = 0
        ans = -float('inf')
        for num in nums:
            dp = max(dp + num, num)
            ans = max(ans, dp)

        return ans
```

## 状态定义与转移

**dp 表示以当前元素结尾的、非空连续子数组的最大和。**

转移只有两种选择：

```python
dp = max(dp + num, num)
#        接上前一段    从当前元素重新开始
```

强调“以当前元素结尾”，才能保证连接下一个元素后仍然连续。任何以当前位置结尾的非空子数组，要么仅包含当前元素，要么由一个以前一位置结尾的子数组接上当前元素；对于后者，保留其中和最大的状态即可。

ans 保存所有结尾位置的最优值，而非仅返回最后一次 dp。dp 初始为 0，第一次处理时得到当前元素；ans 初始为负无穷，因此全负数组也会选出最大的单个元素，不会错误返回空子数组的和 0。

时间 O(n)，额外空间 O(1)。本次核对逻辑，未运行测试或记录平台通过。
