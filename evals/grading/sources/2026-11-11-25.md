## 我的原始代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        def reverseList(start, end):
            prev, cur = None, start
            while cur:
                tmp = cur.next
                cur.next = prev
                if cur is end:
                    break
                prev, cur = cur, tmp

            return end

        prev = dummy = ListNode(next=head)
        rest = head
        while True:
            for _ in range(k):
                if rest is None:
                    return prev
                ak = rest
                rest = rest.next

            a1 = prev.next
            reverseList(a1, ak)
            a1.next = rest
            prev.next = ak
            prev = rest

        return dummy.next
```

## 思路与 Debug

和 [24 · 两两交换链表中的节点](2026-11-11-24.md) 一样，保存组前驱、组头、组尾和下一组的头。先确认凑够 k 个节点，再把 `prev → a1 → … → ak → rest` 接成 `prev → ak → … → a1 → rest`。

- 数节点时先检查当前节点，再走 next。数完第 k 个才到 None 也算一组；没数满就遇到 None 时，尾段保持原样。
- 翻完后，旧组头 a1 成为本组尾，应设 `prev = a1`。rest 是下一组的头，若设 `prev = rest`，下一轮从 `prev.next` 取组头就会跳过一个节点。
- 剩余不足 k 时应返回 `dummy.next`。prev 是不断变化的组前驱，不能作为整个结果的头。

每轮开始时，rest 与 prev.next 指向同一个节点。数满一组后 rest 移到下一组，再把 prev 更新为 a1，这一关系就恢复了。

## 修正版参考

```python
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        def reverseList(start, end):
            prev, cur = None, start
            while cur:
                tmp = cur.next
                cur.next = prev
                if cur is end:
                    break
                prev, cur = cur, tmp

        prev = dummy = ListNode(next=head)
        rest = head
        while True:
            for _ in range(k):
                if rest is None:
                    return dummy.next
                ak = rest
                rest = rest.next

            a1 = prev.next
            reverseList(a1, ak)
            a1.next = rest
            prev.next = ak
            prev = a1
```

- 时间 O(n)，额外空间 O(1)。每组先数一遍再翻一遍，仍是线性时间。
- 上轮本地复现：`1 → 2 → 3 → 4 → 5`、k = 2 时原版只返回 5，修正版返回 `2 → 1 → 4 → 3 → 5`。修正版在 36 组长度与组大小组合上与参考结果一致。
