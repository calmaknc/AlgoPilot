## 思路：交换前后两段，同时恢复段内顺序

先用 `k %= n` 去掉完整循环。将数组分为前 n-k 个元素组成的 A，以及后 k 个元素组成的 B，目标是把 AB 变为 BA。

设 R 表示翻转：

```text
原数组：          A B
整体翻转：        R(B) R(A)
翻转前 k 个：     B R(A)
翻转剩余部分：    B A
```

整体翻转交换两段的位置，但也反转了各段内部顺序；再分别翻转两段，就恢复了内部顺序，从而完成向右移动 k 位。

例子：`[1, 2, 3, 4, 5, 6, 7]`，k = 3。

```text
整体翻转：     [7, 6, 5, 4, 3, 2, 1]
翻转前 3 个：  [5, 6, 7, 4, 3, 2, 1]
翻转后 4 个：  [5, 6, 7, 1, 2, 3, 4]
```

## 我的代码

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        def reverse(i, j):
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j -= 1

        n = len(nums)
        k %= n
        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)
```

## 边界与复杂度

- reverse 使用闭区间 `[i, j]`，两端向中间交换，原地完成。
- k 取模后为 0 时，`reverse(0, -1)` 不执行；另外两次翻转相互抵消，结果仍正确。可选择提前返回以省去操作，但不是正确性所必需。
- n = 1 或 k 大于数组长度时，取模后同样可以处理。
- 代码按题目数组非空的条件使用；若扩展到空数组，需要在取模前提前返回，避免除以零。
- 时间 O(n)，额外空间 O(1)。没有使用切片构造新数组。
