## 我的代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def removeNthFromEnd(self, head: ListNode | None, n: int) -> ListNode | None:
        dummy = ListNode(next=head)
        target_pre = dummy
        tmp = head
        for _ in range(n):
            tmp = tmp.next

        while tmp:
            tmp = tmp.next
            target_pre = target_pre.next

        target = target_pre.next
        target_next = target.next
        del target
        target_pre.next = target_next
        return dummy.next
```

## 为什么快指针先走 n 步

目标是找到待删节点的**前驱**，这样才能改写前驱的 next。让 tmp 从 head 出发先走 n 步，target_pre 从 dummy 出发。之后两个指针同步前进，直到 tmp 到达 None。

设链表长 L，原头下标为 0，dummy 的下标视为 -1。tmp 先走 n 步后，还需走 L-n 步到达末尾之后；target_pre 同样走 L-n 步，就停在下标 L-n-1，下一节点下标 L-n，正是倒数第 n 个节点。

当 n = L 时，tmp 先走 n 步就到达 None，target_pre 留在 dummy，能用同样的操作删除原头节点。返回 `dummy.next`，而不是旧 head。

## 删除节点只需改写链接

原代码中的 `del target` 只解除局部变量与节点的绑定；此时前驱仍然指向该节点。真正让节点从链表中脱离的是将前驱接到它的后继。末尾可以简化为：

```python
target_pre.next = target_pre.next.next
return dummy.next
```

- 按题目给定的 `1 <= n <= L` 使用。时间 O(L)，额外空间 O(1)。
