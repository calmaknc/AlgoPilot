## 思路

用 i、j 表示当前层左上角，M、N 表示该层的行数、列数。依次沿上、右、下、左四条边遍历，再令左上角各向内移动一步，行列数各减 2，继续处理内层。

每条边的起止点要避开前面已经访问的角点；最后一层还可能退化为一行或一列，需要额外判断，避免两条边重合。

## 我的原始代码

```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]:
        ans = []
        def rotate(i, j, M, N):
            nonlocal ans
            for dj in range(N):
                ans.append(matrix[i][j + dj])
            for di in range(1, M):
                ans.append(matrix[i + di][j + N - 1])
            for dj in range(N - 2, -1, -1):
                ans.append(matrix[i + M - 1][j + dj])
            for di in range(M - 2, 0, -1):
                ans.append(matrix[i + di][j])

        m, n = len(matrix), len(matrix[0])
        i, j = 0, 0
        while m > 0 and n > 0:
            rotate(i, j, m, n)
            i += 1
            j += 1
            m -= 2
            n -= 2

        return ans
```

## Bug：退化层的边会重合

### 只剩一行：上边与下边重合

```text
输入：[[1, 2, 3]]
原版输出：[1, 2, 3, 2, 1]
正确输出：[1, 2, 3]
```

第一段已遍历整行，第三段又从右向左重复访问。只有 M > 1，即存在不同于上边的下边时，才执行第三段。

### 只剩一列：右边与左边重合

```text
输入：[[1], [2], [3], [4]]
原版输出：[1, 2, 3, 4, 3, 2]
正确输出：[1, 2, 3, 4]
```

第一段访问顶端，第二段已向下遍历余下整列，第四段又沿同一列向上重复访问。只有 N > 1，即存在不同于右边的左边时，才执行第四段。

不能只检查原矩阵是否单行或单列：外层剥除后，内部也可能出现这样的退化层，必须在每次 rotate 中判断当前的 M、N。

```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]:

            i += 1
            j += 1
            m -= 2
            n -= 2

        return ans
```

## 循环边界与 nonlocal

| 遍历方向 | 偏移范围 | 避免重复的方法 |
| --- | --- | --- |
| 上边向右 | 列偏移 0～N-1 | 包含两个上角点 |
| 右边向下 | 行偏移 1～M-1 | 跳过右上角 |
| 下边向左 | 列偏移 N-2～0 | 跳过右下角；仅 M > 1 时执行 |
| 左边向上 | 行偏移 M-2～1 | 跳过左下角、左上角；仅 N > 1 时执行 |

1×1 时仅第一段执行一次；1×N 时仅第一段访问元素；M×1 时第一段访问顶端，第二段访问剩余元素，均不会重复。

nonlocal ans 可以删除：内部只通过 `ans.append()` 修改已有列表，没有对变量 ans 重新赋值，因此不需要 nonlocal。

## 复杂度与验证边界

- 时间 O(mn)，每个元素恰好访问一次。
- 不计输出数组，额外空间 O(1)；rotate 是普通函数调用，不是递归，不会随层数累积调用栈。
- 按题目矩阵非空的条件使用；不修改输入矩阵。
