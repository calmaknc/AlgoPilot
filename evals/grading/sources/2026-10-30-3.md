## 我的原始代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = [-1] * 26
        ans = 0
        start = 0
        for i, ch in enumerate(s):
            last_ch = last[ord(ch) - ord('a')]
            start = max(last_ch, start)
            ans = max(ans, i - start)
            last[ord(ch) - ord('a')] = i

        return ans
```

## 问题一：混用了两种边界定义

先明确 start 表示什么，再决定初始值、更新公式和长度公式。

| start 的含义 | 初始值 | 更新公式，prev 为字符上次出现的位置 | 当前窗口长度 |
| --- | --- | --- | --- |
| 窗口第一个字符的下标 | 0 | `start = max(start, prev + 1)` | `i - start + 1` |
| 窗口左边界的前一个位置，即排除到哪里 | -1 | `start = max(start, prev)` | `i - start` |

原程序的更新与长度公式使用第二种约定，初始化却写成第一种约定的 0。比如 `s = "a"`，原程序返回 0，正确答案为 1；`s = "abc"` 返回 2，正确答案为 3。

如果保留第二种约定，边界方面只需把 start 初始值改成 -1；若使用更直观的第一种约定，则初始值保留 0，更新与长度两处都需要加 1。两种约定都正确，不能混用。

## 问题二：26 个位置只能表示小写英文字母

原版使用 `ord(ch) - ord('a')` 作为下标，不能适应本题中的数字、符号、空格等字符。例如输入一个空格 `" "` 时，本地下标越界。

改用字典 `last[ch]` 保存字符的最近出现位置，无须假设字符只限于 a～z。未出现过时用 -1。

## 滑动窗口的原理

以下统一使用第一种约定：start 是窗口第一个字符的下标，窗口为闭区间 `[start, i]`。

维护的性质是：**每轮处理完当前字符后，窗口内没有重复字符，且 start 是以 i 结尾的无重复子串能取到的最靠左位置。** 因此本轮窗口就是以 i 结尾的最长无重复子串，对所有 i 取最大长度即可得到全局答案。

处理新字符 ch 之前，原窗口已经没有重复字符；加入 ch 后，只有 ch 可能带来重复。设其上次出现位置为 prev：

- 若 prev 在窗口内，必须排除旧 ch，即把左边界移到 `prev + 1`。
- 若 prev 已在窗口外，原窗口没有 ch，无须移动左边界。
- 若 ch 从未出现，视作 `prev = -1`，同样不移动。

新窗口是原来的无重复窗口去掉一段前缀，再加入已消除冲突的 ch，所以仍然无重复。左边界又只移动到必要的位置，保留了尽可能长的合法后缀。

## 为什么确定 start 要使用 max

本人追问：“因为不能确定重复的字母是出现在开头，还是出现在中间。”

更准确的区分是：**上次出现的位置在当前窗口内，还是已经在窗口外**。若在窗口内，无论位于开头还是中间，都应移到它后面；若在窗口外，则不能让 start 倒退。

因此：

```python
start = max(start, prev + 1)
```

它等价于：

```python
if prev >= start:
    start = prev + 1
# 否则保持 start 不变
```

两项分别代表两个约束：

1. `start`：此前的字符冲突已经要求窗口至少从这里开始，不能退回去。
2. `prev + 1`：为了排除当前字符的旧位置，窗口至少要从这里开始。

**取 max 是同时满足这两个下界，并选择最小的合法新起点。** 不是重复字符一出现就无条件重设起点。

### 关键例子：abba

| i | ch | prev | 更新前 start | 更新后 start | 当前窗口 | 长度 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | a | -1 | 0 | max(0, 0) = 0 | a | 1 |
| 1 | b | -1 | 0 | max(0, 0) = 0 | ab | 2 |
| 2 | b | 1 | 0 | max(0, 2) = 2 | b | 1 |
| 3 | a | 0 | 2 | max(2, 1) = 2 | ba | 2 |

处理最后一个 a 时，旧 a 在下标 0，已经在当前窗口外。如果直接令 `start = prev + 1 = 1`，左边界倒退，窗口变成 `bba`，重新引入之前已经排除的重复 b。使用 max 才能保持 start 为 2，得到合法窗口 ba。

字典记录的是整个已遍历前缀中字符的最近位置，不只记录窗口内部字符。因此其中可能有窗口外的旧记录，必须通过 max 判断它是否仍然构成约束。

## 修正参考代码

本人反馈理解后修改并提交通过。以下为此前助手讲解的字典版参考，不作为本人最终提交源码的逐字记录：

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}
        ans = 0
        start = 0

        for i, ch in enumerate(s):
            prev = last.get(ch, -1)
            start = max(start, prev + 1)
            ans = max(ans, i - start + 1)
            last[ch] = i

        return ans
```

先读取上次位置，再把当前下标写入 last，避免把当前字符误认为自身的历史重复。

## 复杂度与验证边界

- 时间平均 O(n)：每个字符遍历一次，字典查询、更新平均 O(1)，start 直接跳到所需位置。
- 额外空间 O(d)，d 为字符串中的不同字符数，最坏 O(n)。
- 上一轮本地运行原版：空串返回 0；a 返回 0；abc 返回 2；abba 返回 2（该例碰巧正确）；空格触发 IndexError。
- 上一轮助手参考修正版对字符集 `a`、`b`、空格，长度 0～6 的全部 1,093 个字符串，与暴力枚举子串的结果对照通过。这是小规模本地验证，不是平台提交。
- 平台修正版通过依据本人反馈。

## 复习时记住

**右边界逐个扩展；左边界只向右移动，消除当前窗口中的重复；边界定义与长度公式必须一致。**

`max(start, prev + 1)` 的核心是：旧字符若还在窗口内就排除它，若已在窗口外就不回退。
