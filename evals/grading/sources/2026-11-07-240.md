## 我的原始代码

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        up, down = 0, len(matrix)
        while up < down:
            mid = (up + down) // 2
            if matrix[mid][0] > target:
                down = mid
            else:
                up = mid

        left, right = 0, len(matrix[0])
        while left < right:
            mid = (left + right) // 2
            if matrix[up][mid] > target:
                right = mid
            else:
                left = mid

        return matrix[up][left] == target
```

独立运行需导入 `from typing import List`。

## 问题一：边界不前进，二分可能死循环

原版使用下取整中点，但两段循环分别令 `up = mid`、`left = mid`。当左右边界相差 1 时，mid 等于左边界，更新后区间完全不变。

本地对 `[[1, 4], [2, 5]]`、target = 4 做有限步跟踪，第一段状态为：

```text
(up, down, mid)
(0, 2, 1)
(1, 2, 1)
(1, 2, 1)
……
```

第二段同样有这个问题。修改时不能只机械地给某处加 1，而要先统一搜索目标和区间定义。

### 一套完整的左闭右开二分约定

寻找有序数组中第一个大于等于 target 的位置：

```python
left, right = 0, len(row)
while left < right:
    mid = (left + right) // 2
    if row[mid] < target:
        left = mid + 1
    else:
        right = mid
```

- row[mid] < target：mid 及其左侧都不满足条件，排除它们。
- row[mid] >= target：mid 可能就是答案，将它保留为右边界，继续检查更早的位置。
- 每轮区间都缩小，不会停在相同边界。
- 结束后 left == right，表示第一个满足条件的位置，也可能是 len(row)。它是“插入位置”，不保证目标实际存在，因此还需检查下标有效且元素等于 target。

更精确的边界性质：`[0, left)` 都小于 target，`[right, n)` 都大于等于 target；尚未判定的区域为 `[left, right)`。答案可以等于右边界，不应把“搜索区间右开”误解为答案不能落在那里。

## 问题二：240 题不能按每行首元素选定唯一一行

题目仅保证每行从左到右、每列从上到下有序，不保证上一行末尾小于下一行开头。各行的数值范围可能重叠。

```text
matrix = [
    [1, 4],
    [2, 5]
]
target = 4
```

即使二分正确找出了首元素不大于 target 的最后一行，也只会选中 `[2, 5]`，但目标 4 实际在上一行。因此修复死循环后，仍不能沿用只搜索选定一行的策略。

这里“行首不大于目标”只是候选行的必要条件，不能据此排除更早的行。

## 方法一：逐行二分

每一行都已排序，可以分别寻找第一个 >= target 的位置，并检查是否相等。

以下为助手讲解参考实现，未记录本人采用或提交：

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        for row in matrix:
            left, right = 0, len(row)

            while left < right:
                mid = (left + right) // 2
                if row[mid] < target:
                    left = mid + 1
                else:
                    right = mid

            if left < len(row) and row[left] == target:
                return True

        return False
```

设矩阵为 m×n，时间 O(m log(n+1))，额外空间 O(1)。写 log(n+1) 也覆盖 n=1 时每行仍需常数次操作的情况。

## 方法二：从右上角开始，每次排除一行或一列

当前候选矩形为：

```text
行：[i, m-1]
列：[0, j]
```

当前位置 `(i, j)` 是这个区域的右上角：在该区域中，它是所在行的最大值，也是所在列的最小值。

| 当前值与 target 的关系 | 可以排除什么 | 移动 |
| --- | --- | --- |
| 当前值 > target | 第 j 列从 i 向下都不小于当前值，全部太大，排除这一列 | j -= 1 |
| 当前值 < target | 第 i 行从 j 向左都不大于当前值，全部太小，排除这一行 | i += 1 |
| 当前值 == target | 找到 | 返回 True |

每一步都依据单调性证明整行或整列不可能包含目标，而不是只凭感觉选择移动方向。排除后，剩余候选仍为右上角对应的矩形，性质可以继续使用。

### 例子：寻找 5

```text
1 4 7
2 5 8
3 6 9

从 7 开始：7 > 5，排除最后一列，左移到 4。
4 < 5，排除第一行，下移到 5。
5 == 5，找到。
```

为什么不从左上角开始？左上角的右侧、下侧都更大；当前值小于目标时，两边都可能有答案，不能根据一次比较选择一个方向并安全排除另一边。右上角恰好一边更小、一边更大，才能利用比较结果排除。

以下为助手讲解参考实现，按题目矩阵非空的条件使用：

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        i, j = 0, n - 1

        while i < m and j >= 0:
            curr = matrix[i][j]

            if curr == target:
                return True
            elif curr > target:
                j -= 1
            else:
                i += 1

        return False
```

行号只增加、列号只减少，比较次数至多 m+n-1 次，因此时间 O(m+n)，额外空间 O(1)。出界表示所有候选均已排除，返回 False。
