## 思路与易错点

按左端点升序排序，i 指向当前合并组的起点，j 向后扩展，end 保存当前组的最大右端点。

**end 表示所有已合并区间的最远右边界，不是最后一个区间的右端点。** 加入新区间时必须使用：

```python
end = max(end, intervals[j + 1][1])
```

排序只保证左端点递增，右端点可能变小。比如 `[1, 10]` 包含 `[2, 3]`，合并后右端点仍为 10，不能退回 3。

判断下一个区间能否合并，也必须用累计的 end，而不能只比较相邻原始区间的端点。

讲解反例（并非本人提供的原始错误输入）：

```text
[[1, 10], [2, 3], [4, 5]]

合并前两个后，end 仍为 10。
下一个区间的左端点 4 <= 10，所以也应合并。
正确结果：[[1, 10]]。

若错误地把 end 改成 3，或只用 [2, 3] 的右端点比较，
就会误判 [4, 5] 不能加入同一组。
```

本题区间包含端点，因此相接也应合并：`[1, 4]` 与 `[4, 5]` 合并为 `[1, 5]`，判断使用 `>=`。

如果下一个左端点大于 end，由于后续左端点只会更大，当前组就可以结束，写入答案后从 j+1 开始下一组。

## 我的通过代码

```python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        intervals.sort(key = lambda x: x[0])
        ans = []
        i = 0
        while i < len(intervals):
            j = i
            end = intervals[i][1]
            while j < len(intervals) - 1 and end >= intervals[j + 1][0]:
                end = max(end, intervals[j + 1][1])
                j += 1
            ans.append([intervals[i][0], end])
            i = j + 1

        return ans
```

## 复杂度与验证边界

- 时间 O(n log n)，由排序主导；分组扫描总共 O(n)，不会因两层 while 变为 O(n²)。
- Python 排序最坏需要 O(n) 辅助空间，扫描本身 O(1)；输出空间另计，最坏 O(n)。
- sort 会原地调整输入区间的排列顺序。

一句话复习：**左端点排序，右端点维护累计最大值；用累计右边界判断能否继续合并。**
