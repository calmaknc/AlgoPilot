## 我的思路

暴力枚举两条边配对需要 O(n²)。容量由宽度乘以较矮边的高度决定，因此左右各维护一个指针，每次记录容量，再将较矮的一边向中间移动，最终取最大值。

## 为什么可以移动短板

本人理解：当左边比右边矮时，左边就是容量瓶颈，改变右边的高度也无法超过当前容量。

需要补足条件：**固定左边，让右边向内移动**。不能只谈高度而忽略宽度。

设当前 `height[left] <= height[right]`，则当前容量为：

```text
A = (right - left) * height[left]
```

对任意 `left < j < right`，固定 left、改用 j 作为右边时：

```text
新容量 = (j - left) * min(height[left], height[j])
       <= (j - left) * height[left]
       <= (right - left) * height[left]
       = A
```

因此，当前容量记录后，保留 left、继续向内寻找右边不会获得更优结果，可以排除 left，令其右移。右边较矮时同理。每一步排除的边都无法在当前区间内产生更优解，因此不会漏掉全局最大值。

两边一样高时，可以移动任意一边，代码选择移动 right，也正确。

## 我的代码

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        ans = left = 0
        right = len(height) - 1
        while left < right:
            area = (right - left) * min(height[left], height[right])
            ans = max(ans, area)
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return ans
```

- 时间复杂度：O(n)，每轮指针间距缩小 1；额外空间：O(1)。
