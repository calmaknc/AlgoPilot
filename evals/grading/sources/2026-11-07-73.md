## 我的思路

通常可用长度为 m、n 的两个数组，记录每行、每列是否有零。为了将额外空间降为 O(1)，借用矩阵自身的第 0 列和第 0 行作为标记：

- `matrix[i][0] == 0`：第 i 行需要置零。
- `matrix[0][j] == 0`：第 j 列需要置零。

首行、首列同时承担标记功能，修改后不能再据此判断它们原本是否含零，因此在写入标记之前，用两个布尔变量分别保存原始状态。matrix[0][0] 是两者共用的位置，不能单独表达两个独立状态。

## 执行顺序与注意点

1. 先保存首行、首列原本是否含零。
2. 扫描内部区域，遇到原始零时，仅写入该行、该列对应的标记。
3. 根据标记，将内部区域需要清零的元素置零。
4. 最后根据两个布尔变量，分别处理首列、首行。

不能遇到零就立刻清整行整列，再继续把新产生的零当作原始零使用，否则会错误扩散。先标记后统一置零，将原始信息与置零结果分开。

标记必须等内部区域处理完成后才能清除。例如首行原本有零，若提前把整条首行清零，所有列标记都会变成零，导致内部所有列都被误清零。先清首列同理会污染行标记。

在标记完成后，首行首列原本就存在的零也自然发挥标记作用；两个额外布尔值只负责决定首行、首列自身是否需要整条置零。

## 我的代码

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        m, n = len(matrix), len(matrix[0])
        first_row_has_zero = 0 in matrix[0]
        first_col_has_zero = any(row[0] == 0 for row in matrix)
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_col_has_zero:
            for row in matrix:
                row[0] = 0
        if first_row_has_zero:
            for j in range(n):
                matrix[0][j] = 0
```

## 复杂度与验证边界

- 时间 O(mn)，额外空间 O(1)，原地修改矩阵。
- `any(row[0] == 0 for row in matrix)` 使用生成器，没有建立长度为 m 的新列表。
- 单行或单列时，内部扫描自然跳过，最后通过保存的状态完成处理。
- 代码按题目矩阵非空的条件使用。
