## 我的原始代码

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        p_set = [0] * 26
        for ch in p:
            p_set[ord(ch) - ord('a')] += 1

        ans = []
        start = 0
        s_sub_set = [0] * 26
        for j, ch in enumerate(s):
            ch_idx = ord(ch) - ord('a')
            s_sub_set[ch_idx] += 1
            while s_sub_set[ch_idx] > p_set[ch_idx]:
                s_sub_set[ord(s[start]) - ord('a')] -= 1
                start += 1
            if j - start + 1 == len(p):
                ans.append(start)
                s_sub_set[ord(s[start]) - ord('a')] -= 1
                start += 1

        return ans
```

原程序正确。p_set、s_sub_set 实际是字符计数数组，不是 Python 集合；以下参考实现改名为 target、counts，使含义更明确。本题输入为小写英文字母，因此可以使用 26 个计数位置。

## 窗口维护的性质

每轮 while 结束后，**窗口中每种字符的数量都不超过 p 中对应字符的数量**。

加入当前字符之前，这个性质已经成立；加入后只有当前字符可能超量。因此 while 只需检查当前字符的计数，而不用检查全部 26 项。不断移出左端字符，直到当前字符不再超量，所有计数便重新满足限制。

在所有计数均不超过目标的前提下，如果窗口长度又等于 len(p)，则各项计数必然全部相等：如果某一项少了，为了维持总长度就必然有另一项多了，与不超过目标的条件矛盾。因此只判断长度就足以确认异位词。

## 为什么可以删掉 if 中的两行缩窗代码

找到答案时，窗口的计数已经与 p 完全一致。下一轮加入任意一个新字符，它的计数一定超量：

- 若字符出现在 p 中，原本数量已恰好等于目标，再加入一个就超量。
- 若字符不在 p 中，目标数量为 0，加入一个也超量。

因此下一轮 while 会自然执行必要的缩窗，不必在找到答案后提前移出左端字符。保留原窗口不会漏解或重复记录同一个起点。

注意：while 可能需要移出多个字符，不一定只移出一个；目标是一直缩到当前字符不再超量。

例子：`s = "abab"`，`p = "ab"`。

```text
窗口 ab，记录起点 0，保留窗口。
加入 a，窗口成为 aba，a 超量。
while 移出左端 a，得到 ba，记录起点 1。
加入 b，窗口成为 bab，b 超量。
while 移出左端 b，得到 ab，记录起点 2。
```

### 删除重复缩窗后的参考代码

以下为助手整理的参考实现，非本人另行提供的提交源码：

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        target = [0] * 26
        for ch in p:
            target[ord(ch) - ord('a')] += 1

        ans = []
        start = 0
        counts = [0] * 26

        for j, ch in enumerate(s):
            idx = ord(ch) - ord('a')
            counts[idx] += 1

            while counts[idx] > target[idx]:
                counts[ord(s[start]) - ord('a')] -= 1
                start += 1

            if j - start + 1 == len(p):
                ans.append(start)

        return ans
```

## 固定长度窗口写法

异位词长度一定等于 len(p)，因此可以直接维护最近 len(p) 个字符的计数，而不要求每种字符都不超量。

每次加入右端字符；如果窗口长度超过 m，就移出下标 j-m 的字符。窗口凑够 m 个字符后，比较计数数组即可。

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        m = len(p)
        if len(s) < m:
            return []

        target = [0] * 26
        window = [0] * 26
        for ch in p:
            target[ord(ch) - ord('a')] += 1

        ans = []
        for j, ch in enumerate(s):
            window[ord(ch) - ord('a')] += 1

            if j >= m:
                window[ord(s[j - m]) - ord('a')] -= 1

            if j >= m - 1 and window == target:
                ans.append(j - m + 1)

        return ans
```

| 方法 | 维护的性质 | 判断答案 |
| --- | --- | --- |
| 原版与简化版 | 各字符计数不超过目标 | 长度达到 m |
| 固定窗口 | 长度始终不超过 m | 长度达到 m 且计数相等 |

## window == target 能否直接比较两个 list 的内容

可以。Python 列表的 == 比较长度是否相同、对应位置的元素是否相等。顺序有意义，不是只比较有哪些元素。

这里第 0～25 项固定代表 a～z，所以对应计数相等，恰好代表每种字母的出现次数相同。列表每次重新创建也不影响 == 的内容比较。

本人随后联想到 is 和 == 的区别，这个理解正确：

- `==`：比较值是否相等。对这里的整数列表，就是比较列表内容。
- `is`：比较对象身份，即是否为同一个对象。

```python
a = [1, 2, 0]
b = [1, 2, 0]
c = a

a == b          # True：内容相等
a is b          # False：两个分别创建的列表
a is c          # True：c 和 a 指向同一个列表
[1, 2] == [2, 1]  # False：对应位置不同
```

因此固定窗口中使用 `window == target`，不能替换成 `window is target`。

## 复杂度、效率与验证

- 设 s 长度为 n，p 长度为 m。
- 原版、简化版：时间 O(n+m)，左右边界各自最多移动 n 次，不能看到 while 就认为是 O(n²)。
- 固定窗口：时间 O(m+26n)，固定字母表下写作 O(n+m)。列表相等比较最坏检查 26 项，并非任意长度列表都能 O(1) 比较。
- 三个版本排除输出后的额外空间均为 O(26)，固定字母表下即 O(1)；答案列表空间另计。
- 可进一步维护不匹配的字符种类数，省去每次比较 26 项，但需要更复杂的更新逻辑；不改变这里的线性时间量级。未进行性能测量，不能断言某版本实际更快。
