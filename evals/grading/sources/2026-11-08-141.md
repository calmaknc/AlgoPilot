## 为什么相遇就能判环

快慢指针都从 head 出发，慢指针每轮走一步，快指针每轮走两步。**先移动，再判断是否相遇**，否则两个指针初始就都在 head，会误判。

- 无环时，两个指针经过的步数不同，因此移动后不会指向同一个节点；fast 最终到达链表末尾，循环结束。
- 有环时，两个指针最终都会进入环。此后每轮快指针相对慢指针多走一步，两者沿环的距离按环长取模，每轮缩短一格，最多再过一个环长就会相遇。

判断的是是否指向**同一个节点**，用 `slow is fast`；节点的值可能重复，不能比较节点值来判环。

## 参考代码

以下是从本人 142 题代码中拆出的判环部分，不是另行提供的提交源码：

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False
```

- 时间 O(n)，额外空间 O(1)，不修改链表。
