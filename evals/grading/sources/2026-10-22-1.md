## 我的思路

用字典 `record` 保存已遍历元素的值及其下标。遍历到 `num` 时，查找补数 `target - num` 是否已经出现；若出现，返回补数的下标与当前下标，否则将当前元素记入字典。

先查找、再插入，保证使用两个不同下标，也能处理两个数值相同的情况。例如 `nums=[3,3]`、`target=6`：第一个 3 被记录，第二个 3 到来时返回 `[0,1]`。

## 我的代码

原样保留：

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        record = dict()
        for i, num in enumerate(nums):
            if target - num in record:
                return [record[target - num], i]
            record[nums[i]] = i
        return []
```

## 复杂度与验证

- 时间复杂度：平均 O(n)，字典查找和插入平均 O(1)。
- 空间复杂度：O(n)，最多保存线性数量的元素。
